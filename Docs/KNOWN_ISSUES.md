# KNOWN_ISSUES — Open Bugs & Failed Attempts

## Status: LIVE

> The "do not rediscover" list. Two jobs: (1) **open known defects** that are not yet fixed, and (2) **approaches that were tried and failed**, so no future agent (with a fresh context) retries a dead end. This file is the compact, always-active version of that knowledge. Per the global cross-project lessons (`~/.claude/LESSONS.md` §3.5): _read your own known-open list before writing any spec._

---

## 1. When to read and update (the triggers)

A written rule with no moment at which it fires does not work — so:

| Moment                                                                      | Action                                                                                                               |
| --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Before writing any SPEC or fix task**                                     | Read this file. If the defect or a failed approach is already listed, scope around it — do not rediscover it.        |
| **A defect is found and NOT fixed in the same task**                        | Add an open-bug row before the task closes.                                                                          |
| **A fix or approach fails** (esp. after `WHEN_STUCK.md`'s two-attempt stop) | Add a failed-attempt row: what was tried, why it failed.                                                             |
| **A listed bug gets fixed**                                                 | Mark it **Resolved** with the fix reference (decision or date) — do not silently delete the row (the trail matters). |
| **Doc audit** (`Governance/DOC_AUDIT.md`)                                   | Check every resolved row older than one audit cycle is cleared out to the log below the tables.                      |
