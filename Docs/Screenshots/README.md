## Index first

`_INDEX.md` lists one line per image — what it shows and which doc it belongs to. Add a row whenever you add an image, and follow the naming rule there: `YYYY-MM-DD_area_state.png`. This keeps the folder legible to an AI that can't grasp the contents from filenames alone.
