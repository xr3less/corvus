# Marketing

Positioning, launch plans, and distribution/channel drafts.

- Freeform filenames; date them if they iterate (e.g. `launch-plan-2026-01.md`).
- External URLs are allowed here (unlike Governance/numbered docs).
- Marketing changes the founder should know about get reported in conversation, in plain language — not in a doc layer.
- Distribution is usually the real bottleneck — treat this folder as seriously as the engineering docs.
