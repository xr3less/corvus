# 03 — Validation Plan

## Status: DRAFT (filled 2026-09-07 — ceremony SKIPPED per D-017; funnel metrics replace it)

> Formal success-bar ceremony skipped: category demand proven by competitor revenue (~$1,666 MRR / 175 subs). This doc now defines the REPLACEMENT: trial-funnel metrics + pivot triggers.

---

## 1. The core assumption to test

Corvus's onboarding (panel interview → template → simulate → publish) converts trial strangers into publishing owners at a rate that funds growth — i.e. OUR execution, not the category, is what remains unproven.

---

## 2. The test

First strangers from Discord + Twitter/X + Reddit (founder direction). They sign up (no card), get 100 credits / 3 days / 1 bot, and we watch funnel + behavior. No staged sessions — real unsupervised use, instrumented.

---

## 3. Success / fail bar (metrics read, not ceremony)

| Signal | Read as | Response |
|---|---|---|
| trial→publish ≥ 25% over first 100 trials | Execution works | Proceed to Phase 4 (billing wiring, Studio) |
| trial→publish 10–25% | Friction somewhere | Fix top drop-off step, re-read next 100 |
| trial→publish < 10% or day-3 conversion ≈ 0 | Execution fails | Pivot per data (interview findings decide direction) |
| K1/K2/K3 trips at any point | Economics fail | Stop and re-scope per the tripped number |

---

## 4. Recruiting (distribution is the real bottleneck)

Founder direction (2026-09-07): first users from Discord + Twitter/X + Reddit (r/Discord_Bots and adjacent). No paid acquisition pre-validation. Track per-channel: invites -> trials -> publishes -> day-14 retention. Distribution map (top.gg listing, 2 builds/week YouTube, Product Hunt) ships with the shareable URL.

---

## 5. Session script

No staged sessions in V1. Instead: watch first strangers unsupervised; record where they stall (connect? interview? template? simulate? publish?) via funnel + session replay notes; capture reactions as quotes in `Screenshots/` with dates. If a step stalls >40% of triallists, it becomes the next fix task — no meeting required.
